# Сакура, салон красоты

Сайт салона красоты «Сакура» в Ханты-Мансийске: ул. Доронина, 7, 1 этаж.
Запись: +7 952 692-05-05, +7 (3467) 32-11-11. Instagram: sakura.beauty86.

## Что где лежит

| Путь | Что это |
|---|---|
| `site/` | Готовый сайт: `index.html` и папка `assets/` (стили, скрипты, шрифты, логотип, фото салона). Эту папку выкладывают на хостинг. |
| `sakura-preview.html` | Весь сайт одним файлом, открывается двойным щелчком. |
| `sakura-site.pdf` | Сайт в PDF, по разделу на страницу. |
| `sakura-site.zip` | Папка `site/` в архиве. |
| `components/ui/` | React-компоненты (shadcn): анимированный фон, карточки цен, анимированный текст и другие. |
| `src/` | Сборка «островков» React для сайта: фон, карточки цен, анимация заголовков. |
| `logo/` | Ранние варианты логотипа. Основной логотип салона: `site/assets/logo-mark.webp`. |
| `review/` | Прежние версии страницы и старые картинки на случай, если что-то нужно вернуть. |

## Как поменять сайт

Тексты, телефоны и разделы правятся в `site/index.html`, цвета и оформление в `site/assets/style.css`, прайс в `site/assets/app.js` (массив `DATA`).

Если менялись файлы в `components/` или `src/`, пересоберите:

```bash
npm install
npm run build:all
```

Затем пересоберите файл-превью:

```bash
python3 build-artifact.py
```

## Как выложить в интернет

Подойдёт любой хостинг статических сайтов: GitHub Pages, Netlify, Vercel, Hostinger. Выкладывается содержимое папки `site/`.
